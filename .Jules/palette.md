## 2026-06-26 - [Pricing Accordion] Accessibility Fixes for Interactive Elements
**Learning:** Observed a pattern in the application where interactive elements like accordion buttons use `focus:outline-none` without providing a visual focus fallback, rendering them inaccessible for keyboard navigation. Additionally, they often lack proper ARIA relationships linking controls to content.
**Action:** Replaced `focus:outline-none` with `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[brandColor]` across interactive elements to ensure visual focus states are present for keyboard users while keeping click interactions clean. Always add `aria-expanded`, `aria-controls`, and `role="region"` to accordion patterns.
