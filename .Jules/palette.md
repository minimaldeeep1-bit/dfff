## 2026-06-20 - Interactive Div Accessibility
**Learning:** Using `div`s with `onClick` handlers creates inaccessible interactions. Screen readers and keyboard users cannot easily interact with them. Without `tabIndex={0}`, `role="button"`, and manual `onKeyDown` handling for Enter and Space keys, these interactive elements cause a keyboard navigation trap or are completely skipped.
**Action:** Always prefer native `<button>` or `<a>` elements for interactivity. If a custom `div` interaction is necessary (like an image card gallery), ensure it implements the full button ARIA pattern: `role="button"`, `tabIndex={0}`, `aria-label`, and `onKeyDown` handlers for activation via keyboard.
