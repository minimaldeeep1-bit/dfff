## 2026-06-09 - Keyboard Focus and ARIA Connections
**Learning:** Found elements using `focus:outline-none` which completely removes keyboard focus visibility, creating a significant accessibility barrier. Additionally, interactive components like accordions and mobile menus were missing the ARIA attributes (like `aria-controls`, `aria-expanded`, and corresponding `id`s on panels) needed to properly communicate their relationships and states to screen readers.
**Action:** When hiding the default browser outline, always replace it with a `focus-visible` alternative (e.g., `focus-visible:ring-2`) to maintain keyboard accessibility. Always ensure that buttons toggling panels are linked to those panels via `aria-controls` and have an accurate `aria-expanded` state.
