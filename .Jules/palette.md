## 2026-06-21 - Semantic Interactive Elements & Keyboard Modal Nav
**Learning:** Wrapping interactive elements like images in `<div>` with `onClick` breaks keyboard accessibility (no tab indexing or keyboard activation). Modals/Lightboxes are expected by screen-reader and keyboard users to be navigable using standard keys (Escape, ArrowLeft, ArrowRight).
**Action:** Next time, always use semantic `<button>` tags for interactive elements triggering modals, with clear `aria-label` attributes and visible focus states. Ensure lightboxes include global keydown listeners for standard modal navigation.
